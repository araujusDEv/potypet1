# PotyPet 4.7.0 — conferência e preparação

Esta é a versão do software após revisão local. Abertura para usuários reais permanece pendente. Consulte [README.md](README.md), [ATUALIZACAO-4.7.0.md](ATUALIZACAO-4.7.0.md), [GUIA-HOSPEDAGEM.md](GUIA-HOSPEDAGEM.md), [PENDENCIAS-OPERACIONAIS.md](PENDENCIAS-OPERACIONAIS.md) e [relatório final](../RELATORIO-FINAL.md).

O manifesto registra hashes de todos os arquivos do pacote, exceto o próprio manifesto, para evitar autorreferência. O SHA-256 do ZIP é externo. Não contém node_modules, bancos operacionais, chaves, segredos, caches, backups ou arquivos de e-mail dos testes. Exemplos originais estão identificados em EXEMPLOS-E-DADOS.md.

PUBLIC_BASE_URL é explícita e a arquitetura não depende de um provedor. Arquivos do Render permanecem como opção; nenhum foi aplicado. Sucesso em API, Chrome local, backup local ou transporte fictício não comprova SMTP, entrega em caixa postal, persistência na hospedagem, recuperação externa ou pagamento real.
