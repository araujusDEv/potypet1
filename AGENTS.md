# Convenções do projeto

- Use exatamente **PotyPet** como nome público nas próximas etapas. Este projeto é o original Node.js/SQLite; não use uma prévia visual como base.
- Preserve símbolo, cores, estilos, dados e correções anteriores. Mude textos públicos de forma direcionada.
- Preserve identificadores técnicos necessários à compatibilidade: banco, cookies, chaves, rotas, IDs, parâmetros, enums, formatos de backup e variáveis. Consulte ORIGEM-E-COMPATIBILIDADE.md.
- Não substitua palavras em dados existentes. Novos termos de adoção registram brandName e legalNote; documentos antigos mantêm sua origem. Mensagens/fila/auditorias antigas não são renomeadas.
- Atualize e execute os testes de marca sem retirar suas verificações. Valide os fluxos afetados em celular/desktop e nos dois temas.
- A revisão final local foi solicitada para a versão **4.7.0**. Esta versão identifica a revisão do software; responsáveis, documentos públicos finais e operação no provedor continuam pendentes antes de usuários reais. Preserve as evidências e não atribua aprovação de produção a testes locais.
- Não publique nem altere domínio ou hospedagem sem instrução específica do usuário.
